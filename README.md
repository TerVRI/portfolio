## Product snapshots

### RoundCaddy
**Live:** [roundcaddy.com](https://roundcaddy.com)  
Strokes-gained analytics with GPS shot tracking, course map overlays, coach portal, and weather-adjusted distances.  
**Stack:** Next.js · React Native · Apple Watch · Supabase · GitHub Actions CI  
**Repo:** `TerVRI/golfstats` (private monorepo)

### BeatDeck
**Live:** [beatdeckapp.com](https://beatdeckapp.com)  
Native iOS/Android party game with global leaderboards and production observability.  
**Stack:** Swift · Kotlin · PostHog · Sentry · TestFlight / Play internal testing

### Scoilius
**Live:** [scoileus.com](https://scoileus.com)  
UDL lesson modes, Wave 1/2/3 tiered supports, GPT-4 tutor, ElevenLabs voice, PWA.  
**Stack:** Next.js · Supabase · OpenAI · ElevenLabs  
**Repo:** `TerVRI/Rang4mentor` (private)

### SafeFamily
Family safety platform — DNS-level parental controls, child-safe AI chat (on-device + cloud gateway), session monitoring with purge-on-close, eIDAS-aware age verification architecture.  
**Stack:** Kubernetes · Docker · Postgres · Redis · ClickHouse · custom DNS resolver  
**Repo:** `TerVRI/safefamily` (private) · Public status: [safefamily-status](https://github.com/TerVRI/safefamily-status)

### TourPro
Tour operations — financial settlements, show P&L, Duffel flight/hotel APIs, Xero export, crew logistics, offline sync.  
**Stack:** Supabase · Vercel · Slack integrations · LLM-assisted workflows  
**Repo:** `TerVRI/TourPro` (private)

### PC.ie
AI-assisted hardware reviews — automated GPT-4o pipeline, headless CMS, EU-hosted data.  
**Stack:** Next.js · Hetzner Postgres · AWS S3 (eu-west-1) · Vercel  
**Repo:** `TerVRI/pc.ie` (private)
